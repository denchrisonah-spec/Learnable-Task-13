# UserHub – User Management System

A React + TypeScript app that fetches users from an API, stores them in Redux Toolkit, and lets you view, add, edit, and delete users.
## Tech Stack

- React 18 + TypeScript
- Redux Toolkit (global state)
- React Router v6 (routing)
- Vite (build tool)

## Features

- Fetches initial user data from JSONPlaceholder API
- Add, edit, and delete users (managed locally in Redux — no API calls)
- Live search by name, email, or city
- Stats bar showing total members, cities, and current results
